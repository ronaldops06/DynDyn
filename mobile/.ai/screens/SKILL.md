# React Native Modal Auxiliar Register

## Fluxo obrigatório

1. Leia nesta ordem:
    - `.ai/screens/CONTEXT.md`
    - `.ai/screens/patterns.md`
    - `.ai/screens/conventions.md`

2. Identifique o tipo de tela/componente e carregue o template correspondente:

| Tipo     | Template |
|----------|----------|
| Cadastro Auxiliar (modal) | `.ai/templates/screen/auxiliary-register-modal-index.md` + `.ai/templates/screen/auxiliary-register-modal-styles.md` |
| Tela de Listagem          | `não implementado` |
| Cadastro                  | `não implementado` |
| Cadastro Complementar     | `não implementado` |

- Se o tipo de tela ou componente não estiver claro, pergunte antes de gerar

3. Siga **rigorosamente** o template escolhido + as regras dos arquivos `patterns.md` e `conventions.md`.
4. Substitua apenas os placeholders (`Xxx`, `Yyy`, `xxx`, `yyy`...).
5. Gere todos os arquivos necessários (index + styles).
